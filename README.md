## AntiGrifInventory



Блокирует предметы из конфига для игроков с малым временем игры

#### Комманды:
 - /antigrifinventory <reload|check>

#### Права:
 - antigrifinventory.use - Основное право для использования команд [включено поумочанию]
 - antigrifinventory.reload - Позволяет перезагружать конфиг [OP]
 - antigrifinventory.bypass -  Игнорировать блокировку предметов (игрок может брать всё) [OP]

Minecraft paper 1.21.11
